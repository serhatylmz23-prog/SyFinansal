# SyFinansOtağı PWA v5.0 (GitHub Ready) SyFinans Otağı; **Canlı AFAD/Kandilli Deprem API**, **Gerçek Zamanlı Trafik Flow/Radar Bildirim Motoru**, **Eller Serbest (Hands-Free) Sesli AI Asistan**, **Görsel/Video Taramalı Özel Kasa** ve **AI Otonom Özellik Onay Guardrail** sistemini birleştiren simülasyon ve analiz PWA platformudur. --- ## 🛑 Önemli Mimarilik Notu: Simülasyon Mantığı & Güvenlik Kuralı * **Simülasyon Sınırı:** Uygulama içerisindeki tüm alım/satım tavsiyeleri, portföy değerleri ve işlem butonları **sanal simülasyon** mantığında çalışır; gerçek yatırım veya finansal işlem gerçekleştirmez. * **AI Otonom Araştırma & Kullanıcı Onay Motoru:** Kaşif AI internet üzerinde faydalı yeni bir özellik veya canlı API kaynağı bulduğunda kendi başına sisteme eklemez (`app.promptUserForFeatureApproval()`). Kullanıcının önüne onay kartı çıkararak **kullanıcı onayı olmadan hiçbir kararı devreye sokmaz.** --- ## 🛠️ GitHub Pages Kurulum Rehberi 1. GitHub üzerinde **public** bir depo (repository) oluşturun (Örn: `syfinans-pwa`). 2. Proje dosyalarını (`index.html`, `js/app.js`, `manifest.json`, `sw.js`, `README.md`, `icons/` klasörü) reponun **kök dizinine (root)** yükleyin. 3. **Settings -> Pages** menüsüne gidin. 4. **Branch**: `main` veya `master` seçip `/ (root)` klasörünü kaydedin. 5. Yayınlanan adresi telefon/tablette açıp **"Ana Ekrana Ekle"** butonuna dokunun. --- ## 🌟 v5.0 Güncelleme Detayları 1. **AFAD & Kandilli Canlı Deprem API Entegrasyonu:** * AFAD REST API (`GetEventsByFilter`) üzerinden anlık son sarsıntı akışı. * M5.5 ve üzeri depremlerde alarmlı sesli uyarı ve sakinleştirici ses yönlendirmesi. * Hands-free **"💚 GÜVENDEDİM"** butonu ile ağa ve kişilere anında bilgi iletimi. 2. **Gerçek Zamanlı Yol / Trafik / Radar / EDS Asistanı:** * Açık harita verileri ve canlı trafik akışları üzerinden sürücüye eller serbest sesli radar/çevirme uyarısı. 3. **Kaşif AI Otomatik Taramalar & Onay Kartı Guardrail:** * Asistan internet üzerinde yeni belge, veri kaynağı veya modül bulduğunda kanıtlarıyla kullanıcıya sunar; kullanıcı "Onayla" demeden kararları yürürlüğe koymaz. 4. **Siyah Zemin / Gri Yazı Sade Banner:** * Siyah arka plan, gri/beyaz tipografi ile sadeleştirilmiş ve ekran kayması yapmayan yasal uyarı şeridi. 5. **Çift Tıklama Büyütme Engeli:** * `double-tap zoom` engellenmiş; yakınlaştırma tamamen iki parmakla manuel kontrol esnekliğine bırakılmıştır.
